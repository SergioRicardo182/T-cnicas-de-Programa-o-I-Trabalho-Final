# Técnicas-de-Programação-I-Trabalho-Final
Professor: David Holanda Galdino Módulo: DS-PY-004, Técnicas de Programação I (Python)

Projeto de análise exploratória desenvolvido em Python com o objetivo de identificar os principais fatores que levam clientes a cancelarem seus cartões de crédito (*churn*).

## Sobre a Base de Dados

* **Base utilizada:** `BankChurners.csv` (10.127 registros de clientes, contendo informações demográficas, categoria de cartão, histórico de produtos, volume de transações e uso de limite).
* **Origem:** Dataset público disponibilizado na plataforma **Kaggle** (*Credit Card Customers*).

## 🛠️ Ferramentas Utilizadas

* **Linguagem:** Python
* **Bibliotecas:** Pandas, Matplotlib e Seaborn
* **Ambiente:** Google Colab

## 🔍 Principais Perguntas Respondidas

1. Qual a taxa geral de cancelamento e como ela se comporta por faixa de renda e categoria de cartão?
2. Clientes com menos produtos contratados tendem a cancelar mais?
3. Como a inatividade e o número de contatos com o suporte influenciam o cancelamento?
4. Qual a diferença no volume e na frequência de transações entre clientes ativos e cancelados?
5. O limite de crédito e a taxa de utilização do cartão impactam na decisão de saída?
